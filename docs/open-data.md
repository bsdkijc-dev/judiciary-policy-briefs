# Open Judicial Data Catalogue

## `PB-JUD-2026-001`: Indonesia Judiciary Caseload and Clearance Statistics (2015–2025)
- **Dataset Version**: `1.0.0`
- **Reporting Period**: 2015–2025 (19 records across 18 official institutional sources)
- **Verification Status**: `12 VERIFIED`, `4 PARTIALLY VERIFIED`, `3 DISCREPANCY IDENTIFIED` (0 unverified; 0 imputed)
- **Kaggle Profile**: [`https://www.kaggle.com/judicialcollege/datasets`](https://www.kaggle.com/judicialcollege/datasets) *(upload package staged; pending remote publication)*

### Files Included
- [`judicial_caseload.csv`](../../data/PB-JUD-2026-001/judicial_caseload.csv) — Normalized caseload, disposition, pending, productivity, and clearance rates.
- [`source_register.csv`](../../data/PB-JUD-2026-001/source_register.csv) — Full provenance register with official URLs and verification status.
- [`data_dictionary.csv`](../../data/PB-JUD-2026-001/data_dictionary.csv) — Variable definitions, data types, units, and standards.
- [`validation_status.csv`](../../data/PB-JUD-2026-001/validation_status.csv) — Automated schema, integrity, and reconciliation audit results.
