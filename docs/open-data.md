# Open Judicial Data Catalogue

All six datasets in the **Indonesia Judiciary Open Data Initiative (2026 Series)** are published **Public** on Kaggle under `judicialcollege`, backed by full source provenance (`source_register.csv`), data dictionaries (`data_dictionary.csv`), and zero-imputation standards.

| Publication ID | Dataset Title | Reporting Window | Live Kaggle Dataset | GitHub Data Path |
| :--- | :--- | :--- | :--- | :--- |
| `PB-JUD-2026-001` | Indonesia Judiciary Caseload 2015–2025 | 2015–2025 (19 records) | [`indonesia-judiciary-caseload-2015-2025`](https://www.kaggle.com/datasets/judicialcollege/indonesia-judiciary-caseload-2015-2025) ([Notebook](https://www.kaggle.com/code/judicialcollege/judicial-caseload-indonesia-exploratory-analysis)) | [`data/PB-JUD-2026-001/`](../../data/PB-JUD-2026-001/README.md) |
| `PB-JUD-2026-002` | Indonesia Access to Justice and Legal Aid | 2021–2027 (7 records) | [`indonesia-access-to-justice-and-legal-aid`](https://www.kaggle.com/datasets/judicialcollege/indonesia-access-to-justice-and-legal-aid) | [`data/PB-JUD-2026-002/`](../../data/PB-JUD-2026-002/README.md) |
| `PB-JUD-2026-003` | Indonesia Judicial Resources and Capacity | 2018–2025 (8 records) | [`indonesia-judicial-resources-and-capacity`](https://www.kaggle.com/datasets/judicialcollege/indonesia-judicial-resources-and-capacity) | [`data/PB-JUD-2026-003/`](../../data/PB-JUD-2026-003/README.md) |
